## Screenz (Screen Mockup)

A native iOS app built with SwiftUI for creating and exporting device mockups.

## Features

- **Device Frames**: Multiple device presets and finishes (iPhone 17 series, iPhone Air).
- **Customizable Canvas**: Adjustable ratios, background gradients/colors, and bezel styles.
- **Layers & Overlays**: Add and position text and image elements with snapping support.
- **High-Quality Export**: Export compositions as high-resolution images or videos.
- **Local Persistence**: Save and reload projects with bundled assets.

## Requirements

- iOS 17.0+
- Xcode 15.0+
- Swift 5.9+

## Getting Started

1. Open `Screen Mockup.xcodeproj` in Xcode.
2. Select your target simulator or connected iOS device.
3. Build and run (`Cmd + R`).
